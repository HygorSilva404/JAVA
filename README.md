# tipos primitivos
## byte
    - ocupa 8 bits => então vai de -128 a 127
## short
    - ocupa 16 bits => então vai de -32.768 a 32.767
## int
    - ocupa 32 bits => ocupando praticamente todos os valores a serem trabalhados
## long
    - ocupa 64 bits => ocupando uma quatidade mais do que exacerbado 
## float
    - ocupa 32 bits => precisão simples
## double
    -ocupa 64 bits => precisão dupla
## String
    - representa palavras e frases
### char
    - representa um unico caracatere => a,b,c,d
    -ex:char meuChar = 'a' '; => char usa aspas simples
        meuChar = "Fernanda" => strings usam aspas duplas
## booleans
    - true ou false
